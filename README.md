✈️ **XeniaTravel**

A travel-themed single-page application built with React.

🔗 **Live Demo:** [https://xenia19.github.io/xeniatravel/](https://xenia19.github.io/xeniatravel/)

📱 **About**

XeniaTravel is a React-based SPA designed for exploring travel destinations and sharing travel experiences. The app combines static travel-themed sections with dynamic content loaded from a headless CMS. It was developed to practice component-based UI, client-side navigation, and CMS integration. Users can browse destinations, read articles, view travel statistics, and enjoy smooth, animated interactions—all within a responsive layout.

✨ **Features**

* 🌍 Travel-themed sections with static images
* 📝 Dynamic travel articles loaded by country/category via Contentful
* 🗺 Interactive travel map
* 🔢 Animated counters for travel statistics
* 🖼 Gallery and carousel for travel photos
* 🔁 Smooth client-side navigation (SPA)
* 📱 Fully responsive design for different screen sizes
* ⚙️ Fast loading thanks to Create React App and optimized build
* 💻 Articles written in Markdown and managed via Contentful Dashboard
* ✨ CSS animations and interactive UI components

🛠 **Tech Stack**

* **React** — Component-based UI
* **React Router** — Client-side routing
* **Contentful CMS** — Headless CMS for dynamic content
* **SASS / CSS3** — Layout, styling, and animations
* **JavaScript (ES6+)** — Application logic
* **Owl Carousel** — Photo gallery carousel
* **Create React App** — Build pipeline and service worker
* **GitHub Pages** — Deployment
