✈️ **XeniaTravel**

A small React-based travel-themed single-page application.

🔗 **Live Demo:** https://xenia19.github.io/xeniatravel/

---

📱 **About**

XeniaTravel is a simple travel interface built during my early learning with React and frontend development.
The app displays travel-themed sections and images and allows smooth navigation within a single-page layout.
It focuses on clean structure, component-based UI, and practical use of Create React App.

---

✨ **Features**

* 🌍 Travel-themed sections with static images
* 🔁 Smooth client-side navigation (SPA)
* 📱 Responsive layout for different screen sizes
* ⚙️ Fast loading thanks to CRA’s optimized build and auto-generated service worker

---

🛠 **Tech Stack**

* **React** — Component-based UI
* **Create React App** — Webpack build pipeline, optimized production build
* **JavaScript (ES6+)** — Logic, navigation
* **HTML5 / CSS3** — Layout and styling
* **GitHub Pages** — Deployment
